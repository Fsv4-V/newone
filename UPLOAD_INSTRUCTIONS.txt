## How to upload to GitHub

1. Extract this ZIP.
2. Open your GitHub repo: `Fsv4-V/FYP-E-21-430`.
3. Upload/replace these files in the root of the repo:
   - `index.html`
   - `style.css`
   - `script.js`
   - `data.js`
   - `.nojekyll`
   - `README.md`
4. Upload the full `assets` folder.
5. Commit changes.
6. Wait for GitHub Pages deployment.
7. Open the website and press `Ctrl + F5`.

## How to replace generated images with real evidence images

Replace files in `/assets` using the same names:

- `week-01.svg`
- `week-02.svg`
- ...
- `week-14.svg`

You can replace them with `.png` or `.jpg`, but then update the filenames inside `WEEK_MEDIA` at the bottom of `data.js`.
