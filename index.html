Project Abstract

Project Overview

Sensing Principle

Potentiometric pH

PANI working electrode + Ag/AgCl reference measured as a cell potential. This gives direct electronic pH monitoring.

Fabrication

Hand-Fabricated FPCB

Screen printing on PET film with a low-cost Carbon-PANI route suitable for university laboratory prototyping.

Application

Diabetic Wound Monitoring

Continuous pH, temperature and moisture monitoring with a reusable coin-size electronics module.

Clinical Motivation

The Problem We Are Solving

Affordable continuous monitoring can identify wound deterioration between dressing changes.

Clinical Wound pH Reference

The sensor must distinguish acidic healing wounds from alkaline chronic or infected wounds.
